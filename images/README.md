# Imágenes del repo 🎨

Carpeta para guardar recursos visuales de la charla:

- banner del repositorio
- portada de la charla
- visuales para slides
- capturas de demo
- imagen speaker
- recursos para LinkedIn

## Estilo recomendado

- Morado, rosa, azul eléctrico, mint y blanco
- Tech futurista
- Inspiración Stranger Things sin usar personajes ni logos protegidos
- Luces, portales, bicicletas, waffles, walkie-talkies
- Detalles sutiles de flores y mariposas
