# Glosario rápido 🧠

## Microsoft 365 Copilot

Asistente de IA integrado en Microsoft 365 que ayuda a trabajar con información, documentos, reuniones, correos y datos del entorno empresarial.

## Agente inteligente

Sistema que puede recibir un objetivo, entender contexto, razonar sobre pasos posibles y ejecutar acciones dentro de límites definidos.

## Microsoft Graph

Capa que conecta información de personas, documentos, reuniones, chats, correos y relaciones dentro del entorno Microsoft 365.

## Reasoning

Capacidad de analizar una situación, comparar opciones, entender consecuencias y proponer una respuesta más estratégica.

## Memoria contextual

Capacidad de usar información relevante del entorno para adaptar respuestas y acciones.

## Copilot Studio

Herramienta para crear y configurar agentes y experiencias conversacionales conectadas a datos y procesos.

## GitHub Copilot

Asistente de IA para desarrollo que ayuda a escribir, entender, revisar y mejorar código.

## Power Platform

Plataforma low-code de Microsoft para crear apps, automatizaciones, agentes y soluciones de negocio.
