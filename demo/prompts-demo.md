# Prompts de demo ✨

## Prompt 1 — Resumen ejecutivo

```txt
Actúa como un agente de productividad para una responsable de producto.

Necesito un resumen ejecutivo del estado actual de mis proyectos activos.

Incluye:
- estado de cada proyecto
- riesgos identificados
- decisiones pendientes
- personas implicadas
- recomendaciones de próximos pasos
- una propuesta de email breve para stakeholders

Usa un tono profesional, claro y orientado a acción.
```

## Prompt 2 — Identificación de riesgos

```txt
Analiza la información disponible y detecta riesgos en los proyectos.

Clasifica los riesgos por prioridad:
- Alta
- Media
- Baja

Para cada riesgo, indica:
- causa probable
- impacto
- acción recomendada
- persona o equipo que debería intervenir
```

## Prompt 3 — Comunicación para stakeholders

```txt
Redacta un email ejecutivo para stakeholders con:

- resumen del estado general
- principales bloqueos
- decisiones necesarias
- próximos pasos
- tono claro, directo y colaborativo

Evita tecnicismos innecesarios.
```

## Prompt 4 — Versión comunidad

```txt
Reescribe este resumen para explicarlo en una comunidad técnica.

Mantén el rigor, pero hazlo más cercano, visual y fácil de entender para personas que están empezando en IA.
```
