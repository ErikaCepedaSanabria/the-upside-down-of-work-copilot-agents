**Cuando Microsoft 365 Copilot cruza al otro lado**

Repositorio oficial de la charla preparada para **Women for Technical Talks – Anfitrionas: Hablemos de Tecnología**.

Una sesión de 20 minutos, dentro del track de IA, para explicar cómo Microsoft 365 Copilot está evolucionando de asistente a agente inteligente, con una narrativa inspirada en *Stranger Things* y una mirada muy práctica hacia comunidades técnicas, mujeres en tecnología y adopción real de IA.

## 🧠 Abstract

¿Qué ocurre cuando Microsoft 365 Copilot deja de ser solo un asistente y empieza a trabajar como un auténtico agente inteligente?

En esta sesión exploramos el nuevo “Upside Down” del trabajo moderno: agentes, memoria contextual, reasoning avanzado, Microsoft Graph y nuevas formas de automatizar procesos sin perder el foco humano.

Una charla rápida, visual y muy Stranger Things para entender cómo está cambiando la productividad moderna… y por qué el verdadero Upside Down quizá sea seguir trabajando como antes.

---

## ✨ Takeaways

Al terminar la sesión, la audiencia se llevará:

- Una explicación clara de cómo evolucionan los Copilots hacia agentes inteligentes
- Diferencias prácticas entre asistente, automatización y agente
- Ejemplos aplicables en Microsoft 365 Copilot, Copilot Studio, GitHub Copilot y Power Platform
- Ideas para empezar pequeño, sin necesidad de ser developer
- Una visión optimista, práctica y humana sobre el futuro del trabajo con IA
