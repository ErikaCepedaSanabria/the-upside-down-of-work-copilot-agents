# The Upside Down of Work 🧇✨

Charla de 20 minutos para Women for Technical Talks sobre cómo Microsoft 365 Copilot está evolucionando de asistente a agente inteligente.

Inspirada en Stranger Things, esta sesión explica de forma clara, visual y cercana conceptos como:

- Microsoft 365 Copilot
- Agentes inteligentes
- Memoria contextual
- Reasoning avanzado
- Microsoft Graph
- GitHub Copilot Agents
- Work IQ

## 🎤 Sobre la charla

¿Qué ocurre cuando Microsoft 365 Copilot deja de ser solo un asistente y empieza a trabajar como un auténtico agente inteligente?

En esta sesión exploramos el nuevo “Upside Down” del trabajo moderno: menos tareas repetitivas, más contexto, más automatización y más espacio para pensar, crear y conectar.

## 🧠 Nivel

Intermedio, explicado para una audiencia técnica y no técnica.

## 🧇 Temática

Stranger Things, pero sin oscuridad innecesaria: Hawkins, el Upside Down, agentes, señales, portales, café y un poco de magia Copilot.

## 📂 Contenido del repo

- `script/`: guion completo de la charla
- `slides/`: estructura slide by slide y prompt para Gamma
- `demo/`: escenario, prompts y plan B de demo
- `resources/`: enlaces y glosario
- `images/`: ideas visuales para crear imágenes en Canva, Copilot o herramientas de diseño

## ✨ Mensaje principal

Los agentes inteligentes no vienen a sustituirnos.

Vienen a quitarnos el trabajo que nos drena para que podamos dedicar más tiempo a lo que nos hace humanas: pensar, decidir, crear y conectar.
